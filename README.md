# System-Analysis-Design: Meva Application

## What Is Meva

The **Medicaid Employment Verification Application (Meva)** is a colaborative class project aiming to demonstrate 
the student's ability to work on a team using the Agile software development methodology.

The User Stories used for this project are found in AdditionalDocuments > User Stories.docx

## What Framework Does It Use

MEVA uses ASP.Net Core Web App (MVC), a .NET Framework for web applications that uses C#, html, 
Javascript, and css for programming and styling. Bootstrap is also used in MEVA to create 
modern GUI elements and responsive design.

## How To Use

- Make sure you have Visual Studio or Visual Studio Code installed first
- Clone the repository on your device. To clone the repository, go to your terminal, navigate to the folder you want to store the repo in, 
and enter
		```
		git clone https://github.com/Hadas-26/C---System-Analysis-Design
		```
- Run the solution with or without debugging
